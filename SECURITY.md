# Security policy

Please report vulnerabilities in TinyTank, including this skeleton, privately through the framework
repository: [Report a vulnerability](https://github.com/tinytankphp/framework/security/advisories/new).
See its [security policy](https://github.com/tinytankphp/framework/blob/main/SECURITY.md).

A site created from this skeleton is your own: replace this file with your site's own policy.
